# 后台数据工作台升级记录（2026-09-08）

## 本次目标

- 所有后台列表采用固定分页，默认每页 20 条，可切换 50 / 100 条。
- 所有可查询的后台模块提供统一的智利时区筛选：今天、本周、本月和自定义日期。
- 将同一邮箱的真实询盘归入同一个客户档案，并在客户详情中查看其所有已记录的访问路径。

## 实施内容

- 新增 `customer_profiles`、`visitor_sessions`、`visit_events` 三张业务表，并为 `leads` 增加客户、访客和会话关联字段及索引。
- 旧询盘仅按规范化邮箱建立客户档案；不会虚构旧访问路径。新访问路径仅从此次发布后开始记录。
- 公共站点使用第一方随机访客标识记录页面访问。提交询盘时，后端才将该询盘与相同访客标识关联；访问记录中不保存 IP 地址。
- 后台新增“客户中心”和客户详情页，显示相关询盘、访客/会话/浏览量统计和可分页的访问轨迹。
- 后台所有通用资源列表、同步记录、审计记录、SEO 指标和访问分析均接入统一日期筛选；SEO 的日聚合按日字符串过滤，事件数据按真实 UTC 时间过滤后以智利日历显示。
- 首页后台概览的时间显示从上海时区调整为 `America/Santiago`。

## 数据安全与回滚
